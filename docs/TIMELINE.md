# 발연 구간 확정 기록

**프레임 추출이 이 문서에 의존함.** `scripts/colab_extract_smoke.py` 의 시간대는
여기 적힌 값을 옮긴 것이고, 뽑힌 프레임이 왜 뽑혔는지는 여기서만 추적됨.

판정 2026-08-11. 열다섯 개를 **원본 해상도로 초 단위**까지 보고, 경계가 다투어지는
자리는 **0.2초 간격**으로 다시 확인함. 시트(초당 1장, 칸 가로 400px)로 먼저 좁힌 뒤
원본으로 확정하는 순서를 썼음.

## 읽는 법

    모든 초는 **재생 초**임. 배속이나 컷이 있는 출처는 실제 경과 시간과 다름
                            (ft · 05 · j01 · m3 — 각 절에 적어 둠)

    발연        순수 발연. 짙음. **1회차 학습에 쓰는 것은 이것뿐임**
    발연_옅음    냄비 지름만큼 위의 높이에 연기가 못 닿는 구간. 평가군에만 씀
    발연_재가열  한 번 불이 붙었다 꺼진 뒤의 기름 연기. 평가군에만 씀
    발연_조각    2초 이하. 자료원 수에 안 셈
    발연+발화    둘이 섞인 구간. 학습·평가 모두 제외
    발화        불꽃이 보이는 구간
    제외        전환 프레임 · 소화약제 · 그래픽이 덮인 구간. 뽑지 않음
    표시        **제외가 아님.** 프레임은 뽑되 사유를 남겨 두고, 나중에 용도를
                나눌 때 거르기 위한 것임 (사람 등장 · 원거리 · 워터마크 등)

## 각 절에 적은 것

`확인 경위` 는 사용자가 시트에서 판정한 값과 제가 원본에서 확인한 값이 어떻게
달랐는지임. **틀린 쪽이 어디였는지도 그대로 적음** — 사용자 판정이 맞은 경우와
제 안내가 틀려서 어긋난 경우가 둘 다 있음.
