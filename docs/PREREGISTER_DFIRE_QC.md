## 목적
hankookro 공유 `조리 데이터 영상`(급식실 실조리 영상)에서 **① 사용 가능한 영상·학교·조리유형을 확정(QC)** →
**② 학교(장면) 단위 누수 없는 eval/synth 분할** → ③ 프레임 추출 → ④ base(ptrain_b79) FP 재측정.
- **eval** = 실 급식실 무화재 프레임 → FP(헛불) 지표(배포 판정).
- **synth** = 실 급식실 배경 → (A)로 불 합성.
- **(보너스)** 발화 구간 = 실불 양성 후보.

## 왜 QC가 선행 (순서 고정)
분할 규칙의 *입력*(몇 개교·어떤 유형)이 미검증. 부적합 영상을 빼면 **영상 수뿐 아니라 학교·조리유형 수도 줄어** 분할 판단이 바뀜(특히 희소한 볶음·국탕은 1개교 탈락으로 커버 붕괴). 검증 안 된 입력 위에 분할을 등록하면 가정 위에 쌓는 것 → 금지.

## QC 판정 기준 (사전 고정 · FP 수치는 이 단계서 안 봄 = 사용성만)

### 부적합 (탈락) 특징
**A. 기술·무결성 (프로그램 프로브)**
- 디코딩 실패·손상·잘림.
- 실효 프레임 수율 극소(수 초·정지화면 → 중복제거 후 배경 1~2장) = 사실상 기여 0.
- 판독 불가 저해상/깨짐(장면·물체 식별 불가).

**B. 장면·내용 (사용자 풀해상 육안 = 정본)**
- 급식실 조리 장면이 아님(타이틀카드·테스트·무관·빈 화면).
- 화구/조리대가 프레임에 없음(불 자리·혼동원 부재).
- 전 구간 심한 가림 / 극심한 흔들림·패닝 / 완전 암전·과노출.

### ★탈락으로 오인 금지 (표시/부분사용)
- **불·발화 포함 = 탈락 아님, timestamp 표시.** 무화재 구간→배경/음성, 불 구간→실불 양성 후보.
- **저해상 CCTV = 오히려 적합**(배포 화각 일치). "판독 불가 수준"만 탈락.
- **부분 가림·일부 흔들림 = 부분사용**(맑은 프레임만).
- **밝은 조명·스테인리스 반사 = 탈락 사유 아님**(우리가 재려는 FP 트리거).

### 판정 스키마 (영상마다 사유 기록)
- **적합**(용도: 배경/FP음성/양성) · **부분적합**(사유) · **부적합**(사유).

### 역할 분담
- **프로그램(내)**: 디코딩·길이·fps·해상도·프레임수·추정수율·근접중복 + 썸네일 콘택트시트.
- **육안(사용자·풀해상=정본)**: 장면 진위·화구 가시성·가림/흔들림·**불 유무와 timestamp**·불/수증기 애매 판별.

### 잠정 임계 (프로브 분포 보고 확정 — 자동 탈락 아님, 플래그용)
- 배경 샘플 간격 STRIDE=2.0s · 짧음 플래그 <8.0s · 저해상 플래그 짧은변<240px · 추정수율≤2 플래그.

## 다음 단계 규칙 (사전 커밋 · QC 결과 위에서 수치만 채움)
1. **분할 단위 = 학교(=주방=카메라=장면).** 같은 학교 여러 영상은 통째 한쪽. **한 학교의 영상을 eval/synth로 쪼개지 않음**(장면 누수).
2. **층화 = 조리유형(튀김/볶음/국탕).** 가능하면 양쪽에 각 유형.
3. **비율 = eval "충분한 만큼"(다주방·유형커버) / synth "나머지".** 13개교 surplus 기준 eval≈5~6.
4. **초안(잠정, QC 생존자에 재확인) = 튀김 앵커 · 숭곡중→synth.** 근거: synth가 3유형 배경을 가져야 (A) 효과가 세 유형서 해석 가능(교란 방지); 튀김=유탕조리=기름불 주 시나리오라 rigor 앵커. 볶음/국탕은 참고(주방 수 얇음 명시).
5. **FP·수치 보기 전에 분할 확정·등록.** 수치 보고 분할 맞추는 편향 차단.
